  Cause Rate vs. Fixed Rate

  These two numbers appear on the status code detail page and answer different
  questions.

  Cause Rate (shown on each cause as "% OF CASES")

  Question: When this status code happens, how often is this the real cause?

  cause_rate = FIXED incidents of this status code linked to this cause
               ÷ all FIXED incidents of this status code

  - An incident is linked to a cause through the solution the technician picked:
    each solution belongs to exactly one cause.
  - Count only FIXED incidents. A NOT_FIXED or PENDING incident doesn't confirm
    the cause, so it is excluded.
  - Use the same time window as the occurrence count (last 90 days).
  - Purpose: rank causes so technicians check the most likely one first.

  Example (CODE 012, 40 confirmed incidents):

  ┌───────────────┬─────────────────────┬───────────────┐
  │     Cause     │ Confirmed incidents │  Cause rate   │
  ├───────────────┼─────────────────────┼───────────────┤
  │ Nozzle jam    │ 25                  │ 25 ÷ 40 = 62% │
  ├───────────────┼─────────────────────┼───────────────┤
  │ Belt loose    │ 10                  │ 10 ÷ 40 = 25% │
  ├───────────────┼─────────────────────┼───────────────┤
  │ Encoder cable │ 5                   │ 5 ÷ 40 = 12%  │
  └───────────────┴─────────────────────┴───────────────┘

  All the cause rates for one status code add up to about 100%, give or take
  rounding.

  Fixed Rate (shown on each solution as "FIXED RATE")

  Question: When someone tries this solution, how often does it actually fix the
  machine?

  fixed_rate = incidents using this solution with result = FIXED
               ÷ incidents using this solution with result = FIXED or NOT_FIXED

  - Exclude PENDING incidents. The outcome isn't known yet.
  - Purpose: rank solutions inside a cause so the most reliable one is on top.

  Example ("Reset servo driver", used 18 times): 16 fixed, 2 not fixed, so 16 ÷
  18 = 89%.

  Fixed rates are independent of each other and do not add up to 100%.

  Side-by-side

  ┌──────────────┬───────────────────────────────┬─────────────────────────┐
  │              │          Cause Rate           │       Fixed Rate        │
  ├──────────────┼───────────────────────────────┼─────────────────────────┤
  │ Belongs to   │ Cause                         │ Solution                │
  ├──────────────┼───────────────────────────────┼─────────────────────────┤
  │ Measures     │ How common the cause is       │ How reliable the fix is │
  ├──────────────┼───────────────────────────────┼─────────────────────────┤
  │ Counts       │ FIXED only                    │ FIXED and NOT_FIXED     │
  ├──────────────┼───────────────────────────────┼─────────────────────────┤
  │ Sums to      │ Yes, across causes of one     │ No                      │
  │ 100%?        │ code                          │                         │
  ├──────────────┼───────────────────────────────┼─────────────────────────┤
  │ Used to sort │ Causes                        │ Solutions within a      │
  │              │                               │ cause                   │
  └──────────────┴───────────────────────────────┴─────────────────────────┘

  Implementation notes

  - Both are calculated by the backend. The frontend only displays cause_rate
    and fixed_rate from the API. Do not calculate them in React.
  - Low sample size: if the denominator is under 5, show NEW (or 3 uses) instead
    of a percentage. One success shouldn't display as "100%".
  - Fixed Rate colors: ≥ 80% green, 50–79% amber, < 50% red. Cause Rate stays
    neutral gray, because a common cause isn't good or bad.
  - Rounding: round down to whole numbers. A cause or solution with no data
    shows —, not 0%.

  ---

  Two of these are rules I'm proposing, not settled decisions, so check them
  with the team before this goes to the devs: cause rate counting FIXED only,
  and the minimum of 5 incidents before showing a percentage. I can also put
  this into the board 2 sticky on the canvas.
